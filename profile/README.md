## What we build

ResilientMQ is an open source toolkit for building **fault-tolerant, event-driven Node.js services** on RabbitMQ.

It keeps retry policy, dead-letter routing, idempotency and event lifecycle state out of business handlers, while allowing applications to choose how that state is persisted.

> A redelivered event should be a normal case, not an incident.
